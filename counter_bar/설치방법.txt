========================================================
  CounterBar.exe (매장 카운터 PC 상단 3버튼 툴바) 설치 안내
========================================================

[기능 요약]
- 화면 위 항상 떠 있는 초경량 툴바 (47KB / 별도 설치 불필요)
- 버튼 3개:
  1. [출퇴근]     : 출퇴근기록부 웹앱 실행 / 다시 누르면 최소화·복원 전환
  2. [OK포스]     : OK포스 실행 / 다시 누르면 최소화·복원 전환
  3. [유튜브뮤직] : 유튜브뮤직 전용 창 실행 / 다시 누르면 최소화·복원 전환
                    (최소화해도 배경 음악은 계속 재생됩니다)
- 왼쪽 점 6개(⋮⋮) 부분을 마우스로 끌어 원하는 위치(상단 중앙/우측 등)에 배치 가능
  (위치 자동 저장)
- 실행 중인 앱은 버튼 우측 상단에 작은 초록 점이 표시됩니다.

[카운터 PC 설치 방법 — 1분 완료]
1. CounterBar.exe 파일을 카운터 PC의 고정된 폴더에 복사합니다.
   예) C:\CounterBar\CounterBar.exe  (또는 바탕화면)
2. CounterBar.exe를 더블클릭해 실행합니다.
   (Windows SmartScreen 경고가 뜨면 "추가 정보" → "실행" 클릭)
3. 툴바 맨 오른쪽 [톱니바퀴(설정)] 버튼을 누릅니다.
4. "OK포스 실행 파일 또는 바로가기 경로"에서 [찾아보기...]를 눌러
   카운터 PC의 OK포스(.exe 또는 바탕화면 바로가기 .lnk)를 선택합니다.
5. [✓] Windows 시작 시 자동 실행 (시작프로그램 등록)에 체크 후 [저장]을 누릅니다.

※ 방법 2 (직접 시작프로그램 폴더에 넣기):
   키보드 [Win + R] → shell:startup 입력 후 엔터 → 열리는 폴더에
   CounterBar.exe 바로가기를 넣어두셔도 동일하게 자동 실행됩니다.

[참고]
- 웹 출퇴근 앱을 버전업(배포)해도 CounterBar.exe를 새로 만들 필요 없이
  항상 최신 웹 화면이 그대로 열립니다.
- 툴바를 종료하려면 [톱니바퀴(설정)] → [툴바 종료] 또는
  화면 우측 하단 시계 옆 트레이 아이콘 우클릭 → [툴바 종료]를 누르세요.
